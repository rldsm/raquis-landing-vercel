# Cyber Raquis

Landing Cyber embebible para raquischile.cl.

## Preview
Abrir /cyber/ en el deployment de Vercel.

## Embed
```html
<raquis-cyber></raquis-cyber>
<script src="https://raquis-landing.vercel.app/cyber/raquis-cyber.js" defer></script>
```

## Links de compra
Cada promoción acepta un atributo independiente:
- buy-quiro-10
- buy-quiro-4
- buy-kine-10
- buy-kine-5
- buy-maso-8
- buy-maso-4
- buy-ondas-5
- buy-gift-maso
- buy-gift-quiro

Ejemplo:
```html
<raquis-cyber buy-quiro-10="https://..."></raquis-cyber>
```

## Google Reviews
El componente incluye un slot llamado `google-reviews`, pensado para insertar el contenedor que requiera el widget/script real de reseñas.
